# Passerelle 180 Atlas

프랑스어권 현장의 인프라 요청을 짧은 영상으로 올리고, 본인인증을 거친 전문가가 장면마다 코멘트를 달고, 한국 기업·정부 기관이 참여를 제안하도록 잇는 시연 페이지입니다.
경희대학교 프랑스어학과·아프리카연구소 SDGs 공모전(프랑코포니 × SDG 9) 출품작.

- `index.html` — 시연 페이지. 화면 언어 한국어 / English / Français. 인터넷 없이 더블클릭으로도 열립니다.
- 주소 끝에 `#사례id`를 붙이면 그 영상이 바로 열립니다. 탭까지 지정할 수 있습니다: `#gharb`, `#anyang/summary`, `#dakar/comments`, `#quebec/partner`
- `media/<사례id>/` — `poster.jpg`(1280×720, 영상 화면), `thumb.jpg`(640×360, 첫 화면 카드). 가르브는 영상(720p, 저데이터 480p)과 `fr.srt`·`ko.srt`·`en.srt`도 있습니다.
- `tools/replace_video.py` — 가르브 영상을 편집본으로 바꿀 때 자막 시점·코멘트 시점·썸네일을 함께 맞추는 스크립트
- `tools/srt2lines.py` — 언어별 .srt를 페이지의 자막 데이터로 바꾸는 스크립트

## 화면 구성

**첫 화면** — 사례 카드마다 사진 썸네일, 지역(도시·국가), 분야, 제목, `문제`, `요청`, 핵심 수치, 기업·정부 참여 상태가 보입니다. 오른쪽 위 `표` 버튼을 누르면 지역·제목·문제·요청을 한 표로 볼 수 있고, 분야·지역·검색으로 거를 수 있습니다.

**영상 화면(4개 탭)**
1. **영상** — 자막 켜기/끄기(CC, 단축키 C), 한·영·불 자막 동시 표시, 글자 크기 3단계, 자막 파일(.srt) 내려받기, 전체 화면, 대본 문장을 눌러 이동
2. **사례 요약** — 지역, 현장의 문제, 요청 내용(한국 사례는 제안 내용), 관련 기관, 필요한 협력, SDG, 진행 단계, 핵심 용어, 한국 비교 사례와 출처
3. **전문가 코멘트** — 장면 시각이 붙은 코멘트 목록. 등록과 수정은 본인인증을 마친 사람만 할 수 있고, 수정은 처음 작성할 때 인증한 본인만 할 수 있습니다.
4. **기업·정부 참여** — 참여 단계(참여 기관 모집 → 협의 중 → 참여 확정), 참여 기관, 기업·정부·대학별로 필요한 참여 항목(항목마다 바로 참여 제안), 진행 기록, 연결된 현장 질문

## 본인인증 시연 방법

시연 페이지라 실제 메일·문자는 보내지 않고 인증번호를 화면에 보여 줍니다. 인증은 10분 동안 유효하고, 연락처는 해시와 가린 형태(예: `in***@example.ac.kr`)로만 보관합니다.

- **새 코멘트:** 아무 이름·소속·이메일(또는 휴대전화 번호)로 인증하면 등록됩니다.
- **예시 코멘트 수정:** 작성자 본인 이메일로 인증해야 수정 화면이 열립니다. 다른 연락처로 인증하면 "작성자 본인만 수정할 수 있습니다"가 뜹니다.

| 예시 작성자(가상) | 인증 이메일 |
| --- | --- |
| 프랑스어 통번역 교수 | `interp@example.ac.kr` |
| 수자원 연구자 | `hydro@example.ac.kr` |
| 교통 연구자 | `transport@example.re.kr` |
| 개발협력 실무자 | `devcoop@example.com` |
| 모로코 수자원 엔지니어 | `ingenieur@example.ma` |

| 창업지원단 매니저 | `startup@example.ac.kr` |
| 시설물 점검 연구자 | `bridge-lab@example.ac.kr` |

실제 운영에서는 이 부분을 서버의 메일·문자 인증(또는 휴대전화 본인확인 서비스)으로 바꿔야 합니다. 이 페이지에서 입력한 내용은 저장되지 않으며, 새로고침하면 처음 상태로 돌아갑니다.

## 썸네일 바꾸기

`media/<사례id>/poster.jpg`(1280×720)와 `thumb.jpg`(640×360)를 같은 이름으로 덮어쓰면 됩니다. 16:9 사진이면 아래처럼 한 번에 만들 수 있습니다.

```
ffmpeg -i 새사진.png -vf "scale=1280:720:force_original_aspect_ratio=increase,crop=1280:720" -q:v 3 media/dakar/poster.jpg
ffmpeg -i 새사진.png -vf "scale=640:360:force_original_aspect_ratio=increase,crop=640:360" -q:v 4 media/dakar/thumb.jpg
```

## GitHub에 올리기

**웹에서(가장 쉬움)**
1. 저장소 첫 화면에서 `Add file` → `Upload files`
2. 이 폴더 안의 `index.html`, `README.md`, `media`, `tools`를 한꺼번에 끌어 놓기(폴더째 끌면 경로가 유지됩니다)
3. 아래 `Commit changes`에 메모(예: "사례 6건, 4탭 영상 화면, 본인인증") → `Commit changes`
4. GitHub Pages를 쓰는 중이면 1~2분 뒤 같은 주소에서 바뀐 화면이 보입니다. 처음이면 `Settings` → `Pages` → Branch `main` / `/(root)` → `Save`

웹 업로드는 파일 하나가 25MB를 넘으면 안 됩니다. 지금 가장 큰 파일은 가르브 영상(약 3.7MB)이라 괜찮습니다.

**명령줄에서**
```
git add index.html README.md media tools
git commit -m "사례 6건, 4탭 영상 화면, 본인인증"
git push
```
