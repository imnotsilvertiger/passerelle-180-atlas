# Passerelle 180 Atlas · 시연 페이지

경희대학교 프랑스어학과·아프리카연구소 SDGs 공모전(프랑코포니 × SDG 9) 출품작의 시연 페이지입니다.

- `index.html` — 시연 페이지. 인터넷 없이 더블클릭으로도 열립니다.
- 주소 끝에 `#gharb`를 붙이면 가르브 평야 영상(프랑스어 원음 + KO·FR·EN 자막)이 바로 열립니다.
- `media/gharb/` — 영상(720p, 저용량 480p), 포스터, `fr.srt`·`ko.srt`·`en.srt`
- `tools/srt2lines.py` — 언어별 .srt를 페이지의 자막 데이터로 바꾸는 스크립트

연구자·인터뷰·다리 상태 기록·Q&A·전문가 코멘트 일부는 형식을 보여 주기 위한 가상 견본입니다. 가르브 영상의 화자는 본인 양해를 받고 촬영했습니다.
